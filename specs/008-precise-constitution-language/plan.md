## Summary

Modernize the language of the project constitution, companion standards, templates, presets, agent personas, and documentation. Replace informal, metaphorical, or AI-generated prose (such as "Evidence Over Invention", "primary source digs", and "epistemic truth") with direct, industry-standard software engineering terminology while strictly preserving all underlying governance invariants and fail-closed rules. Additionally, streamline repository documentation (`README.md` and governance sections) to reference upstream GitHub Spec Kit ([`github/spec-kit`](https://github.com/github/spec-kit)) as the foundation project rather than restating its built-in concepts, focusing strictly on the value-add capabilities introduced by this toolkit.
